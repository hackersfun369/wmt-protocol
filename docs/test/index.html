Full API Reference

Complete documentation for every command in the WebTransport Mail Transfer Protocol (WMTP). This reference covers all 57 authenticated and unauthenticated methods implemented in the v1.0 reference server.

🔐 Session & Authentication

1. INIT Initial
Initializes a new ephemeral session.
Request Payload
Key Type Required Description
No payload required
Request
{ "cmd": "INIT" }
2. AUTH Upgrade
Promotes an ephemeral session to an authenticated state using provided user credentials (email).
Request Payload
Key Type Required Description
email string YES User email address
Request
{
  "cmd": "AUTH",
  "data": {
    "email": "test@auto.com"
  }
}
Response
{
  "cmd": "AUTH_OK",
  "status": "OK",
  "msg": "Authentication successful",
  "session_token": "b4fb83e0ac10f0b9e24517f6b26666f2ab6a1ea1579861d2ebffb907a5eac391",
  "auth": true
}
3. RESUME State
Resumes a previous session using a permanent session token.
Request Payload
Key Type Required Description
token string YES Permanent session token
Request
{ "cmd": "RESUME", "data": { "token": "b4fb83e..." } }
4. LOGOUT
Invalidates the current session and clears server-side state.
Request Payload
Key Type Required Description
session_token string YES Active session token
Request
{
  "cmd": "LOGOUT",
  "data": {
    "session_token": "b4fb83e..."
  }
}
Response
{
  "cmd": "LOGOUT",
  "status": "OK",
  "msg": "Logged out"
}
5. SESSION_INFO
Details about the current session status, authentication level, and associated email.
Request Payload
Key Type Required Description
session_token string YES Active session token
Request
{
  "cmd": "SESSION_INFO",
  "data": {
    "session_token": "b4fb83e..."
  }
}
Response
{
  "cmd": "SESSION_INFO",
  "status": "OK",
  "msg": "Session info",
  "session_token": "b4fb83e0ac10f0b9e24517f6b26666f2ab6a1ea1579861d2ebffb907a5eac391",
  "auth": true,
  "email": "test@auto.com"
}
6. SESSION_LIST
Lists all active sessions linked to the authenticated user.
Request Payload
Key Type Required Description
session_token string YES Active session token
Request
{ "cmd": "SESSION_LIST", "data": { "session_token": "..." } }
7. SESSION_KILL
Terminates a specific session by its token.
Request Payload
Key Type Required Description
session_token string YES Active session token
target_token string YES The token to invalidate
Request
{ "cmd": "SESSION_KILL", "data": { "session_token": "...", "target_token": "..." } }
8. SESSION_SUSPEND
Temporarily pauses a session. The token remains valid but requires a specialized resume.
Request Payload
Key Type Required Description
session_token string YES Active session token
Request
{
  "cmd": "SESSION_SUSPEND",
  "data": { "session_token": "auth_..." }
}
9. SESSION_RESUME_SUSPENDED
Resumes a previously suspended session using the original token.
Request Payload
Key Type Required Description
session_token string YES Current (or new) connection token
token string YES The suspended token to resume
Request
{
  "cmd": "SESSION_RESUME_SUSPENDED",
  "data": {
    "session_token": "eph_...",
    "token": "auth_previously_suspended"
  }
}

📡 Health & Diagnostics

10. PING
Basic health check. Responds with PONG and server heartbeat data.
Request
{ "cmd": "PING" }
Response
{
  "cmd": "PONG",
  "status": "OK",
  "msg": "PONG",
  "server_time": "2025-12-23T07:28:12.905+00:00",
  "uptime_seconds": 420
}
11. PONG
Server response to a PING command. Contains timing and state info.
Example Payload (Server Push)
{
  "cmd": "PONG",
  "status": "OK",
  "msg": "PONG",
  "server_time": "2025-12-23T07:28:12.905Z",
  "uptime_seconds": 420
}
12. HB

Request
{ "cmd": "HB" }
Response

  "msg": "Heartbeat acknowledged"

34. MSG_SEND
Sends a message to recipients. Stores a copy in the SENT folder.
Request Payload
Key Type Required Description
session_token string YES Active session token
to array[string] YES List of recipient email addresses
subject string NO Subject line
body string NO Email body content
attachment_ids array[string] NO Upload IDs for attachments
Request
{
  "cmd": "MSG_SEND",
  "data": {
    "session_token": "auth_...",
    "to": ["bob@wmtp.org"],
    "subject": "Hello",
    "body": "Hi Bob!",
    "attachment_ids": ["upl_992"]
  }
}
